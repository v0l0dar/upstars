# 🎬 UPSTARS Video Stories Player

Interactive video player inspired by Instagram Stories, built with **Vue 3**, **TypeScript**, and **Vite**.

---

## 🛠️ Tech Stack

- Vue 3 (Composition API)
- TypeScript
- Vite
- SCSS
- GSAP

---

## ⚙️ Requirements

- **Node.js** `>= 20.0.0` (recommended: `22.x`)
- **npm** `>= 9.6.0`

---

## 📦 Getting Started

```bash
git clone https://github.com/v0l0dar/upstart.git
cd upstart
npm install
npm run dev
```
